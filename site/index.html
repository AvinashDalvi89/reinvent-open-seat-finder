Find sessions you can still get into.

The catalog lists every session, full or not. Open Seats shows only the ones with open seats, plans your day across the Strip, and reserves your picks in one step.

Run it in 2 minutes View on GitHub ↗

Why I built it

My re:Invent looks like this: meetings at Caesars Forum, a talk at the Venetian, lunch somewhere in between, and then a session at MGM that I'd never make in time.

Every “Full” badge was another click wasted. So I built a tool that only shows sessions I can still get into, knows how long it takes to walk (or shuttle) between venues, and fills my free gaps for me.

What it does

Built on the official re:Invent Events API. Your sign-in and data stay on your own machine.

🎟️

Open seats only

Filter by Open, Filling up and Last seats, with live counts. Full sessions are one checkbox away if you want them.

🗓️

My week New

Your day as an agenda in Las Vegas time: reservations, favorites and your own meetings, side by side.

🚶

Travel-time checks New

Knows the Strip from Wynn to Mandalay. Warns you when a hop is too tight, and hides sessions you can't reach in time.

On the laptop

Run it yourself

You need Python 3 and an AWS Builder ID registered for re:Invent 2026. No installs, no dependencies.

  1. Get the code and start it: 
    git clone https://github.com/AvinashDalvi89/reinvent-open-seat-finder.git
cd reinvent-open-seat-finder
python3 server.py
  2. Your browser opens http://localhost:8484. Click Sign in with AWS Builder ID.
  3. Optional: install it as an app. In Chrome or Edge, use the install icon in the address bar.

Why not just a website? The re:Invent Events API only allows sign-in from an app running on your own machine. That's by design: your tokens never leave your laptop.

On the go? Everything you reserve or block in Open Seats lands on your re:Invent schedule, so it shows up in the official re:Invent app on your phone.
